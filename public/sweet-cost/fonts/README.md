# خط ثمانية

ملفات الخط لا تُحفظ في المستودع. نزّلها بأمر واحد:

```
npm run fonts:local
```

بدونها يعمل التطبيق أيضاً — قواعد `@font-face` في `src/sweetcost/styles.css`
تسقط تلقائياً إلى نسخة CDN. التنزيل المحلي يلغي الاعتماد الخارجي ويجعل الخط
يعمل داخل التطبيق المثبّت على الجوال بلا شبكة.

الخط من إنتاج «ثمانية» ومرخّص منها: <https://font.thmanyah.com/licenses>
راجع الترخيص قبل الاستخدام التجاري.
