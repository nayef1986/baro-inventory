# موقع أكواد الخصم

موقع مستقل تمامًا عن بقية مشاريع المستودع: صفحات HTML **ثابتة** مبنية للظهور في نتائج قوقل،
بدون قاعدة بيانات وبدون أي حزم خارجية (Node فقط).

> ⚠️ الأكواد الموجودة حاليًا في `data/stores.json` هي **بيانات تجريبية** (`SAMPLE…`).
> استبدلها بأكواد حقيقية قبل ربط الدومين ونشر الموقع للجمهور.

---

## التشغيل محليًا

```bash
cd coupons
npm run dev      # يبني الموقع ويشغّله على http://localhost:4173
npm run build    # يبني فقط → مجلد dist/
```

لا يحتاج `npm install` — لا توجد أي اعتماديات.

---

## إضافة متجر أو كود جديد

كل شيء في ملف واحد: `data/stores.json`.

```json
{
  "slug": "noon",                    // يظهر في الرابط: /store/noon/ — إنجليزي وبدون مسافات
  "name": "نون",                     // اسم المتجر كما يظهر للزائر
  "url": "https://www.noon.com/",    // رابط المتجر (أو رابط الأفلييت)
  "logo": "/images/noon.png",        // اختياري — اتركه "" ليُولَّد شعار بحرف الاسم الأول
  "brandColor": "#FEEE00",           // لون الشعار المولَّد
  "category": "تسوق عام",            // يُستخدم في أزرار التصنيف بالصفحة الرئيسية
  "description": "وصف قصير للمتجر.",
  "codes": [
    {
      "code": "BARO10",              // الكود نفسه — هو ما يُنسخ
      "title": "خصم 10% على الطلب الأول",
      "discount": "10%",             // يظهر كوسم ملوّن
      "expires": "2026-12-31",       // يُخفى الكود تلقائيًا بعد هذا التاريخ
      "terms": "بحد أدنى 200 ريال.",
      "featured": true               // اختياري — يبرز الكود ويضع وسم «الأكثر استخدامًا»
    }
  ]
}
```

**ملاحظات:**
- الأكواد المنتهية تُحذف من الموقع تلقائيًا عند كل بناء، ومتجر بلا أكواد فعّالة لا تُنشأ له صفحة.
- الشعارات: ضعها في `public/images/` وأشِر إليها بـ `/images/اسم-الملف.png`. الحجم المناسب 200×200 بكسل.
- بعد أي تعديل: اعمل commit و push — Vercel يعيد البناء والنشر تلقائيًا.

## الدومين والظهور في قوقل

1. اشترِ الدومين واربطه بمشروع Vercel.
2. حدّث `"domain"` في `data/site.json` بالدومين الجديد — منه تُبنى روابط `canonical` و `sitemap.xml`.
3. أضف الموقع في [Google Search Console](https://search.google.com/search-console) وأرسل `https://دومينك/sitemap.xml`.

**ما هو مُهيّأ مسبقًا:** صفحة مستقلة لكل متجر، `title` و `description` لكل صفحة،
روابط `canonical`، `sitemap.xml` و `robots.txt`، بيانات منظمة (`Offer` و `FAQPage` و `BreadcrumbList`)،
صور المشاركة (`og.png`)، دعم RTL كامل، وسرعة تحميل عالية لأن الصفحات ثابتة.

روابط المتاجر الخارجية تحمل `rel="nofollow sponsored"` — وهو المطلوب من قوقل لروابط الأفلييت.

## النشر على Vercel

مشروع **جديد ومنفصل** (لا يمس أي مشروع قائم):

| الإعداد | القيمة |
|---|---|
| Repository | `nayef1986/baro-inventory` |
| Root Directory | `coupons` |
| Framework Preset | Other |
| Build Command | `node build.js` |
| Output Directory | `dist` |

الإعدادات الثلاثة الأخيرة مقروءة أصلًا من `vercel.json`، يكفي ضبط **Root Directory**.

## البنية

```
coupons/
├── data/
│   ├── site.json      ← اسم الموقع والدومين والوصف
│   └── stores.json    ← المتاجر والأكواد (هذا الملف تعدّله يوميًا)
├── public/            ← ملفات تُنسخ كما هي: styles.css, app.js, og.png, images/
├── build.js           ← مولّد الصفحات الثابتة
├── serve.js           ← خادم معاينة محلي
└── dist/              ← الناتج (مُستبعد من git)
```
