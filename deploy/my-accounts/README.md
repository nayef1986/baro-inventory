# حساباتي — نشر على Vercel

صفحة حسابات شخصية مستقلة: حسابات بنسب، حركات وارد/صادر، توزيع مبلغ
على الحسابات بالنسب، وتصدير **Excel** وطباعة **PDF** (للكل أو لحساب واحد،
مع فلتر فترة ورصيد افتتاحي).

ملفان `index.html` و`containers.js` بلا بناء — المكتبات من CDN بإصدارات مثبّتة.

## إعدادات مشروع Vercel

```
Root Directory:    deploy/my-accounts
Framework:         Other
Build Command:     (فارغ)
Output Directory:  .
```

مربوط بنفس المستودع — كل دفعة إلى `main` تنشره تلقائياً.

## القاعدة

نفس مشروع Supabase الخاص بـCOCO CAKE (`sweet-cost`)، جدولا
`pa_accounts` و`pa_entries` — انظر `supabase/migrations/0009_personal_accounts.sql`.
نبّاض COCO CAKE اليومي يُبقي القاعدة مستيقظة للتطبيقين.

## الوصول

بخلاف COCO CAKE: **دخول بالبريد وكلمة المرور إلزامي**. كل صف مقفول على
صاحبه (RLS على `auth.uid()`)، والدور `anon` بلا أي صلاحية على الجدولين.

## نسبة الحاويات (التبويب الأول)

جهة واحدة تحاسبك بنسبة (افتراضياً 2.5%) من كل فاتورة حاوية، وتدفع لك
دفعات عامة. الباقي لك = مجموع النسب − مجموع الاستلامات.

- **فاتورة حاوية:** رقم الحاوية والفاتورة والمبلغ، والنسبة تنحسب تلقائياً
  (ويمكن كتابتها مباشرة للفواتير القديمة مجهولة المبلغ).
- **إدخال جماعي:** لصق أسطر من Excel أو الواتساب، أو رفع ملف Excel. يفهم
  التاريخ (اليوم أولاً) والمبلغ ورقم الحاوية بأي ترتيب، والأرقام العربية،
  ويعرض معاينة قبل الحفظ.
- **تنبيه التكرار:** أي حاوية أو فاتورة مسجّلة مرتين تُعلَّم بـ⚠.
- **التصدير:** Excel بثلاث أوراق (كشف الحساب، الفواتير، الاستلامات) وPDF.

الجدولان: `pa_container_invoices` و`pa_commission_receipts` — انظر
`supabase/migrations/0010_container_commissions.sql`.
